# better-driver

Enhanced offline-first GPS navigation for Ukraine with anti-jamming, satellite/hybrid maps.

## Features

- Offline-first navigation
- Anti-jamming support
- Satellite and hybrid map modes
- Built with Flutter

## Getting Started

See [GETTING-STARTED.md](GETTING-STARTED.md) for setup instructions.

## Development

```bash
flutter pub get
flutter test
flutter run
```

## Build

```bash
flutter build apk
flutter build ios
```
